# PrettySumatraPDF — v1.0.2

Release date: 2026-10-21

## Highlights

- Added regular-expression search, with case-sensitive and whole-word options.
- Added a search-results sidebar that groups matches by page and navigates to the selected page.
- Improved responsiveness when opening multiple PDFs from startup or Explorer by loading additional documents asynchronously.
- Show the native application window before initializing the hybrid WebView2 toolbar.
- Added per-tool colors for highlight, underline, and strikeout annotations.
- Improved toolbar keyboard handling, localization, theme synchronization, dropdown state, and accessibility.
- Updated the installer to package the offline WebView UI and its required assets.

## Build artifacts

- Installer: `scripts\installer\dist\PrettySumatraPDF-Setup-1.0.2.exe`
- Application: `out\rel64\SumatraPDF-dll.exe`
