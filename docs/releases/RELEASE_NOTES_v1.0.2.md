# PrettySumatraPDF v1.0.2

Release date: 2026-10-21

## Search

- Search now supports regular expressions, case-sensitive matching, and whole-word matching.
- A results sidebar groups matches by page and shows the number of matches on each page. Select a result to jump to that page and highlight its matches.

## Startup and Toolbar

- Opening several PDFs together from startup or Explorer is more responsive because document loading runs asynchronously.
- The native window appears before the WebView2 toolbar finishes initializing.
- The hybrid toolbar has improved keyboard handling, localization, theme synchronization, dropdown behavior, and accessibility.

## Annotations and Installer

- Highlight, underline, and strikeout tools can each use their own color.
- The installer includes the WebView home page, toolbar, styles, and required fonts and icons for offline use.
